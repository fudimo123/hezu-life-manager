# 🏠 合租生活管家（CoLiving Mate）

> 美团 AI Coding 考试作品 · 面向合租青年的生活协作工具
> **在线地址：https://fudimo123.github.io/hezu-life-manager/**

## 一、产品定位

**一句话：把「口头约定」变成「自动提醒」，把「不好意思开口」变成「系统帮你说」。**

年轻人合租生活中的高频矛盾，几乎都源于「账没算清」和「约定没人执行」。本产品用一个应用整合 **费用 AA 分摊、清洁值日排班、公共物品管理、室友公约管理** 四大场景，通过「记录 — 计算 — 提醒 — 执行」闭环，让合租关系中的每一件事都有据可依、自动运转。

## 二、用户痛点与机会点

| # | 痛点 | 用户原声（调研） | 产品方案 |
|---|------|------------------|----------|
| 1 | 钱算不清 | 「新人只住了 20 天，凭什么摊一整个月水电？」 | 三种分摊算法（均摊 / 按入住天数 / 自定义）+ 自动结算中心 |
| 2 | 活没人干 | 「值日表贴了一个月，动的永远是同一个人。」 | 自动轮值排班 + 到点提醒 + 打卡积分榜 |
| 3 | 东西没人买 | 「垃圾袋用完了才发现，最后都是同一个人默默下单。」 | 物品登记 + 消耗记录 + 低库存预警 + 补货自动入账 |
| 4 | 约定没约束 | 「说好 11 点安静，转头就忘；当面不好意思说。」 | 公约电子化 + 在线投票生效 + 全员签署 + 违约留痕 |

**数据打通设计**：成员「入住/退租日期」是底层关键数据 —— 自动驱动费用按天分摊、值日轮值名单更新，一个数据变更，全屋规则同步更新。

## 四、核心流程

1. **费用结算闭环**：垫付人记一笔 → 选分摊方式 → 系统自动算账 → 结算中心生成「谁转给谁」→ 还款确认结清。
2. **值日执行闭环**：设定任务与频率 → 系统排班 → 到点提醒 → 完成打卡 → 积分入榜。
3. **物品补货闭环**：登记公共物品 → 日常消耗记录 → 低于阈值预警 → 一键补货 → 补货费用入账单。
4. **公约生成闭环**：发起草案 → 室友投票 → 达到比例生效 → 全员签署 → 违约记录留痕。

## 五、核心算法说明

- **AA 均摊**：按账单日活跃成员人数均分，尾差自动摊入最后一人。
- **按入住天数**：按账单周期内每位成员的实际入住天数折算比例（`share = amount × 入住天数 / 总人天`），新室友、退租自动按天计算。
- **自定义**：手动输入每人金额，校验分摊合计与总额一致。
- **自动结算**：`净额 = 垫付 − 应摊`，将债权人与债务人按金额排序匹配，生成**最少笔数**的转账方案（贪心配对）；附一键复制催收话术。
- **对账确认**：室友逐笔确认账单无误，全员确认后标记「已对账」归档。
- **值日轮值**：`值日人 = 轮值名单[(应值日次数 − 1) mod 名单长度]`，按自然日推进；请假自动顺延下一位，天然支持轮休与新人插入。
- **退租清算**：`应退金额 = 押金份额 − 未结清欠款`，与退租日期联动自动计算。

## 八、部署与迭代规范（域名永不更换）

> ⚠️ **项目铁律：作品唯一入口为 `https://fudimo123.github.io/hezu-life-manager/`，所有迭代只更新此站点，禁止更换域名。**

- **域名机制**：GitHub Pages 域名与仓库名（`fudimo123/hezu-life-manager`）永久绑定，仓库不可重命名、不可删除，域名即永久稳定。
- **迭代方式**：更新本仓库代码后重新部署即可，链接不变。两种方式：
  1. 在 GitHub 网页端直接编辑仓库文件，保存后 Pages 自动重新构建（约 1 分钟生效）；
  2. 本地改完代码，用固化脚本部署：
     ```powershell
     $env:GH_TOKEN = (gh auth token)
     node deploy/deploy-pages.js
     ```
     （本机直连 github.com:443 的 git push 被网络阻断，故脚本走 GitHub API 上传；脚本内 OWNER/REPO 为固定常量，自动跳过未变更文件，构建完成后打印不变的站点地址。）

- **痛点解决度自评**（诚实呈现于产品页）：
  - ✅ 已解决：费用分摊、值日排班、物品空窗、公约约束；
  - 🟡 部分：室友匹配（已上线生活标签 + 合拍指数）、社区粘性（已上线家动态 Feed）、AI 智能化（已上线 AI 管家演示版）。
- **本迭代新增功能**：
  1. 🤖 **AI 管家**：催收/还款话术生成（多语气）、公约草案起草（5 模板→一键发起投票）、智能分摊建议（按账单类型推荐→一键记账）；演示版为本地规则引擎，可替换为真实大模型 API；
  2. 🏡 **家动态 Feed**：账单/打卡/补货/公约/违约事件聚合时间线——社区内容沉淀雏形；
  3. 🤝 **成员画像 + 合拍指数**：5 维生活习惯标签（作息/卫生/宠物/烟酒/社交），计算成员间合拍百分比，新室友入住前可评估是否同频；

- **下一步（对应 Wellcee 三个不足的启示）**：AI 走向真实大模型（自动对账、偏好学习）；社区运营（公约广场、生活圈子、家的记忆）；生态开放（与找房平台打通：找房看合拍指数，入住无缝接管）。

## 十二、AI 管家 Provider 模式（真实大模型接入）

AI 管家采用**三层引擎架构**，面试官打开网页即可用真实大模型，**无需任何配置**：

| 优先级 | 引擎 | 说明 |
|--------|------|------|
| 1 | 用户自填 Key | 在「AI 设置」中填自己的 Key（存本机浏览器），覆盖默认引擎 |
| 2 | **官方代理（默认）** | `https://hezu-ai-proxy.fudimo123.deno.net/chat` —— 前端只含代理地址，**不含任何密钥**；密钥存于 Deno Deploy 服务端环境变量（secret 标记），并内置每分钟 60 次限流 |
| 3 | 内置模板引擎 | 代理不可用或调用失败时自动降级，界面永不白屏 |

- **架构**：纯前端静态站（GitHub Pages） → Deno Deploy 边缘函数代理 → DeepSeek API，OpenAI `chat/completions` 兼容协议；
- **部署方式**：`deploy/ai-proxy/` 内含代理源码与部署指南；代理通过 Deno Deploy v2 REST API 部署（本环境 `deno.com` 域名网络受限，故走 `api.deno.com` 而非网页编辑器）；
- **支持厂商**：DeepSeek / 智谱 GLM / Kimi / OpenAI 兼容 / 自定义端点；
- **容错**：请求 20 秒超时保护，任何失败静默降级为内置模板。

## 十三、社区化（P0-P3）与桌面端

**社区属性落地（把「单机工具」变成「真社区」）：**

- **P0 家庭云同步**：成员管理 →「共享之家」创建云端家庭（6 位邀请码 / 邀请链接 `#/app?join=CODE` 自动弹窗加入）；账本 · 值日 · 库存 · 公约**跨设备实时共享**（防抖推送 + 6 秒轮询 + 乐观锁版本合并 + 20 秒在线心跳）；后端为 Deno Deploy 边缘函数（`deploy/ai-proxy/main.ts` 的 `/api/home/*`，存储抽象支持 KV/内存双模式）。
- **P1 家动态互动**：点赞 / 评论 / @室友，随云端家庭实时同步。
- **P2 公约广场**：公约页顶部入口；7 条社区高频模板（含采用数）+ 一键采用 + 分享我家的公约 + 分类筛选。
- **P3 找室友准入评估**：成员管理 →「找室友评估」；输入候选人生活习惯标签 → 与每位成员合拍指数 + 冲突点 + **AI 评估意见** + 建议公约一键发起 + 邀请入住。

**AI 防作弊防越狱（三层护栏）：**

1. **服务端护栏（官方代理）**：提示词由服务端按任务（script/covenant/split/evaluate）构造，客户端无法注入自定义提示词；输入侧拦截注入模式（忽略指令/角色扮演/索要提示词等）与违规话题，返回安全兜底内容；输出侧校验 JSON 结构与提示词泄露标记；来源 Origin 白名单 + 每 IP 分钟限流 + 全局日配额 + 单请求 token 上限。
2. **客户端护栏**：越狱输入本地预拦截、单设备每日 120 次限额、失败静默降级内置模板。
3. **自填 Key 直连时**：客户端构造同款护栏提示词。

**桌面端 Demo（≥1024px）：** 248px 固定侧边栏导航 + 顶栏 + 1280px 双栏画布（`columns: 2 440px`）+ 居中对话框 + hover 悬浮效果 + 键盘快捷键（`1-5` 切页 / `N` 记一笔 / `?` 功能地图 / `Esc` 关闭），功能与移动端完全一致。
