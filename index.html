合租生活，矛盾从哪来？

来自真实合租社区的痛点调研：90% 的室友矛盾，都源于「账没算清」和「约定没人执行」。

💸

钱算不清

「水电燃气按月均摊还是按天算？新人只住了 20 天，凭什么摊一整个月？」

垫付忘记记录、结算时各说各话、催款尴尬。欠款不催伤钱，催了伤感情。

→ 三种分摊算法 + 自动结算中心
🧹

活没人干

「值日表贴在冰箱上，贴了一个月，动的永远是同一个人。」

排班不公平、轮值靠自觉、做完没人知道。公共区域卫生成为合租第一大矛盾源。

→ 自动轮值排班 + 打卡提醒 + 积分榜
📦

东西没人买

「垃圾袋用完了才发现，纸抽永远只剩最后一张，最后都是同一个人默默下单。」

公共物品消耗无记录、补货无提醒，谁买谁吃亏，慢慢变成隐形怨气。

→ 物品登记 + 低库存预警 + 一键补货
📜

约定没约束

「说好 11 点后安静，转头就忘；当面不好意思说，憋着又难受。」

公约口头化、朝令夕改、违约无记录，说理时拿不出任何「证据」。

→ 公约电子化 + 在线投票 + 违约留痕

设计亮点

区别于记账工具与群接龙，我们做的是「合租关系的操作系统」。

🧮

公平的分摊算法

均摊 / 按入住天数 / 自定义比例三种方式；新室友、退租自动按天折算，谁都不吃亏。

🤝

不尴尬的催收

结算中心自动计算「谁该转给谁多少钱」，一键复制转账话术，系统替你说出口。

🔁

全自动轮值

任务只需设定一次，系统按成员顺序自动排班到天；完成打卡得积分，公平看得见。

🚨

库存预警

消耗记录驱动库存变化，低于阈值自动进入首页提醒，补货费用可直接计入账单 AA。

📝

公约即契约

投票生效、全员签署、违约留痕，让「口头约定」升级为可追溯的书面契约。

🔒

隐私与归属

数据 100% 本地存储，不注册不上传；支持一键导出备份，随时迁移。
